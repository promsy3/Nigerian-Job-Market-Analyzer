# 🇳🇬 Nigerian Job Market Analyzer

> Analyzing 250 Nigerian tech job listings to uncover in-demand skills, 
> salary trends, and hiring patterns across the Nigerian tech ecosystem.

## 📊 View the Full Analysis
👉 [Open in Google Colab](https://colab.research.google.com/drive/16iXtquyU9T5etu8eTsu_szMInwo2MNa5?usp=sharing)

## 🔍 Key Findings
| Insight | Result |
|--------|--------|
| Most in-demand skill | SQL |
| Highest paying role | Machine Learning Engineer |
| Average top salary | ₦594,500/month |
| Remote job share | 29.6% |
| Most active employer | Paystack |
| Most common job type | Contract |

## 🛠️ Tools Used
Python • Pandas • Matplotlib • Seaborn • Google Colab
