# 🇳🇬 Nigerian Job Market Analyzer

Analysis of 250 Nigerian tech job listings to uncover in-demand skills, 
salary trends, and hiring patterns.

## 📊 View the Full Analysis
👉 [Open in Google Colab](https://colab.research.google.com/drive/16iXtquyU9T5etu8eTsu_szMInwo2MNa5?usp=sharing)

## Key Findings
- Most in-demand skill: SQL
- Highest paying role: Machine Learning Engineer (₦594,500/month avg)
- 29.6% of jobs are remote
- Top employer: Paystack

## Tools Used
Python | Pandas | Matplotlib | Seaborn | Google Colab
